# ⚾🏀🏎️🌍 まいすぽ | ドラゴンズ・ジェッツ・モータースポーツ・世界スポーツ ニュース要約 ＆ 1週間AI調査レポート

「まいすぽ」は、中日ドラゴンズ、千葉ジェッツふなばし、モータースポーツ（F1・MotoGP・WRC・WEC・Indy等）、世界のメジャースポーツ（MLB・欧州サッカー・NBA等）の最新ニュースを3行要約。過去1週間の試合結果・選手動向・世界選手権の戦況をAIが徹底調査・分析してお届けする無料Webアプリです。

## 🌟 特徴
- **4カテゴリー横一列大型エンブレムナビ**: 中日ドラゴンズ「CD」エンブレム、千葉ジェッツ「戦闘機＆星」エンブレム、モータースポーツ、世界スポーツの4つを横一列に配置し、直感的にワンタップ切り替え
- **30秒要約カード**: 各ニュースの「結論・具体的ポイント3点・ファン注目ポイント」を瞬時に把握（Gemini 3.5 Flash-Lite による高品質要約）
- **過去1週間のAI調査レポート**: 試合結果、首脳陣コメント、注目選手、次戦の展望をAIが深掘り分析して上部にピン留め
- **モータースポーツ欄**: F1、MotoGPを中心に、角田裕毅、小椋藍、中上貴晶、WEC（ル・マン24時間）、WRC（勝田貴元）、Indy、ダカールラリー等の重要ニュースを網羅
- **世界のメジャースポーツ欄**: MLB（大谷翔平、山本由伸等）、欧州サッカー（プレミアリーグ、CL、三笘薫、久保建英等）、NBA（八村塁等）の世界最高峰ニュースを速報
- **左右スワイプ操作**: 指でサッとスワイプして4カテゴリーを快適に横断
- **PWA対応**: スマホのホーム画面に追加してアプリ感覚でサクサク閲覧
- **完全無料・毎朝自動更新**: GitHub Actions（午前6:00 JST）＆ GitHub Pagesで永久無料運用
