# ⚾🏀 ドラ＆ジェッツ速報 | 中日ドラゴンズ & 千葉ジェッツ ニュース要約 ＆ 3日間AI調査レポート

中日ドラゴンズと千葉ジェッツふなばしの最新ニュースを3行要約。過去3日間の試合結果・選手動向をAIが徹底調査・分析して毎朝お届けする無料Webアプリです。

## 🌟 特徴
- **30秒要約カード**: 各ニュースの「結論・ポイント3点・ファン向け一言」を瞬時に把握
- **過去3日間のAI調査レポート**: 試合結果、首脳陣コメント、注目選手、次戦の展望をAIが深掘り分析して上部にピン留め
- **左右スワイプ操作**: 指でサッとスワイプしてドラゴンズとジェッツを切り替え
- **PWA対応**: スマホのホーム画面に追加してアプリ感覚でサクサク閲覧
- **完全無料・毎朝自動更新**: GitHub Actions（午前6:00 JST）＆ GitHub Pagesで永久無料運用

## 🛠️ 技術構成
- **データ取得**: Google News RSS
- **AI要約 & 調査分析**: Gemini 2.5 Flash / 2.0 Flash + スマートフォールバックエンジン
- **自動化**: GitHub Actions
- **ホスティング**: GitHub Pages
